    1. Overview

    This replication package reproduces all tables, figures, and in-text numerical results reported in:
     Tincani, Michela (2026). “Peer Effects and Rank Concerns in the Classroom”, conditionally accepted at the Journal of Political Economy.
    The package contains:
      All code necessary to reproduce the empirical results.

    Notes
      All files inside output/, data/processed, and confidential-data-not-for-publication/processed are generated by the replication scripts.
      The folder data/raw contains all data inputs that the author is permitted to redistribute publicly. These include author-constructed datasets and any third-party
      data for which redistribution is allowed.
      The folder confidential-data-not-for-publication/raw is intended to store restricted administrative datasets that cannot be publicly redistributed. In the
      publicly deposited replication package, this folder will be empty. Researchers seeking to replicate the results must independently obtain the relevant restricted
      datasets from the originating institutions and place them in this folder.
      The folder code/stata contains all Stata do-files used in the analysis, the subfolder ado_frozen/ containing the frozen user-written Stata ado dependencies
      used by the scripts, and the file eb_map_iv_f.txt, which contains starting values for the latent class (LCA) estimation. The starting values are provided to ensure
      numerical reproducibility of the estimation procedure.
      The README is provided in both Markdown (README.md) and PDF (README.pdf) formats; the contents are identical.

    5. Instructions for Replicators: Order of Execution

    Step 0 — Ensure Output Folder Is Empty
    Confirm that:
      output/figures
      output/tables
      output/in_text_numbers
    are empty before running any code. If output is not empty, any existing content may be overwritten when the code is executed.
    Step 1 — Python Preprocessing
    Navigate to:

     code/python 

    Install the required packages as per Section 4.2. Then run:

     python calculate_coastal_proximity.py 

    The script automatically detects the replication package root directory. It generates the intermediate dataset containing the distance of each town from the Chilean
    coastline. This dataset is used by subsequent scripts.
    Step 2 - Stata Data Construction and Analysis
    Open Stata and set the working directory to the root of the replication package (i.e., the folder that contains code/, data/, output/, and confidential-data-not-
    for-publication/).
    Example:

     cd "path/to/Replication_Package_Tincani-20180648" 

    Then run:

     do "code/stata/0_Peer_Effects_and_Rank_Concerns.do" 

    Note: The master do-file 0_Peer_Effects_and_Rank_Concerns.do defines all internal paths relative to the current working directory (using c(pwd)). For this reason,
    replication requires that Stata’s working directory is set to the replication package root before executing the master do-file.
    This do-file:
      Loads the frozen Stata ado files stored in code/stata/ado_frozen
      Runs all Stata programs
      Generates intermediate and final datasets
      Generates tables and figures
      Produces log files containing in-text numbers
    Step 3 — Python Map Creation
    Navigate to:

     code/python 

    Install the required Python packages as described in Section 4.2.
    Then run:

     python create_map.py

    6. Instructions for Replicators: Manual Verification Steps

    6.1 Figure 3 — Donut Graph (Excel-Based)
    The donut graph is constructed in Excel using values generated by Stata.
    The numerical inputs are taken from:

     output/figures/lca_all.log 

    The Excel file used to construct the donut graphs is:

     code/excel/donut_graph_construction_types.xls 

    The Excel file is already populated. Replicators must verify that the values match those in the log file, as per the instructions reported in Sections from 6.1.1 to 6.1.4. For
    convenience, the donut.png file that contains the Figure to be included in the paper has been saved in the code\excel folder. Once the manual verification step is
    complete, replicators must move this file to the output\figure folder to compile the paper.
    6.1.1 Class Fractions (Graph Titles)
    The titles of the three donut charts report class fractions.
    These must match the mean values reported in the log file immediately after:

     sum cpr* 

     Excel Cell Corresponding Log File Value
     B1   Mean of cpr1
     B32   Mean of cpr2
     B63   Mean of cpr3

    6.1.2 Column C: Posterior-Weighted Proportions
    Column C contains posterior-weighted proportions by material type and class.
    Rules:
      Values must be copied directly from the log file.
      If a material number (listed in Column D) does not appear in the log file, set the value to 0.
      No transformations or recalculations should be performed.
    Values correspond to:

     v4a_use | class k 
     v4b_use | class k 
     v4c_use | class k

    6.2 Conley Standard Errors (Table A14)
    code/stata/21_conley.do produces two outputs:
      1. A LaTeX file:

     output/tables/conley_to_edit.tex 

    This file serves as a compilation placeholder that allows the main LaTeX document to compile successfully.
    The table generated from conley_to_edit.tex is not the final version of Table A14 as shown in the published PDF.
      2. A log file:

     output/tables/Table_A14_conley.txt 

    This log file contains the full Conley regression output, including the Conley standard errors.
    To verify reproducibility of Table A14, replicators must:
      Open Table_A14_conley.txt
      Locate the Conley standard errors reported in the regression output, after the ols_spatial_HAC command. These are the standard errors of the variables
      post_st_exp, post_loo_mean_damage, pos_loo_sd_damage, which are the first three in the regression tables. Variable ts is the test score output, variable GPA_std is
      the GPA output.
      Confirm that these standard errors and the p-values match the standard errors and significance stars reported in the published PDF version of Table A14
    The authoritative source for verification of the Conley standard errors is the log file Table_A14_conley.txt, not the placeholder LaTeX file.

    This section documents the computing environments used to prepare the replication package.
    The replication consists of two computational environments:
      1. Local execution (all Stata do-files except Conley, all Python files, the R file)

    8.1 Local Execution Environment (Main Pipeline)
    All do-files except 21_conley.do were executed locally using:
      StataNow 19.5
      Do-files specify version 18
    Hardware
    The following hardware was used for executing the two Python file, the R file, and all do-files except 21_conley.do, :
      Processor: Intel® Core™ Ultra 7 268V 2.20 GHz
      RAM: 32.0 GB (31.6 GB usable)
      System type: 64-bit operating system, x64-based processor
    Runtime
      Full Stata pipeline (excluding Conley): around 7 hours
      This includes:
         Data preparation
         Estimation
         Generation of all tables (except A1, A19, A20)
         Generation of all figures (except Figures 1, 2, 7, 12, A1)
         Generation of all in-text number logs
      R file: less than a minute
